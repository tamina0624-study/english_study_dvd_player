アプリケーション構成図

アプリ内の役割と、DVD・VLC・ローカル保存先との関係を示します。字幕取得は再生制御から独立した処理です。

実線：主な操作・データの流れ。破線：字幕取得への制御。映像はVLCから画面の動画領域へ出力する（図では経路を省略）。ログは各処理からローカル保存先へ記録する。サーバー・外部通信・データベースは使用しない構成。

字幕取得バックエンドは実装時に確定します。本図は「DVD字幕を取得できる」という設計上の前提を表し、実機で取得済みであることを示すものではありません。

1. 目的・前提・設計範囲

仕様書v0.2を実装へつなぐため、責務、画面、データ、主要処理と異常時動作を定める。クラスの詳細、具体的な字幕デコードAPI、依存関係の固定バージョンは詳細設計で確定する。本書は実装・実機動作の完了報告ではない。

  • Python、PySide6、VLC＋python-vlcを採用する方針。Windows上で動作させる。
  • 評価媒体は手持ちのドラマDVD（ユーザー記載名：frieds）。英語・日本語字幕が収録され、取得可能であることを開発上の前提とする。
  • DVDの元の字幕画像を時刻付き一覧として表示する。OCR、翻訳、ネットワークサービス、アカウント、DBは初版の必須構成にしない。
  • ドライブ・タイトル選択とチャプター移動に対応する。DVDメニュー、ISO、一般動画ファイル、実行ファイル化は初版対象外。
  • 再生エンジンの字幕選択と、画像・時刻を取り出す処理は分離する。VLCの再生機能だけで字幕一覧取得が実現するとは仮定しない。

スレッド・イベント

画面操作と描画はGUIスレッドで行う。DVD走査、字幕取得、画像の読み出しはワーカーへ分離し、結果をQtのシグナル等でGUIへ渡す。VLCのコールバックから画面を直接操作しない。媒体・タイトル切替ごとに世代IDを発行し、古い処理の結果は破棄する。

4. 状態と操作制御

状態可能な操作遷移
未読み込みドライブ選択、読み込み、終了読み込み要求で読み込み中。
読み込み中音量、終了成功で再生待機、失敗で未読み込み。
再生待機再生、選択変更、可能なら位置変更、音量、言語切替再生で再生中。
再生中一時停止、停止、シーク、2秒戻し、前後チャプター、言語切替、音量一時停止で一時停止。停止・自然終端で先頭の再生待機。
一時停止再開、停止、シーク、2秒戻し、前後チャプター、言語切替、音量再開で再生中、停止で先頭の再生待機。
再生エラー媒体・タイトル再選択、終了再選択で読み込み中。

位置変更不可の媒体ではシーク・2秒戻しを無効化。前後チャプターは移動先が存在し、移動可能な場合だけ有効。DVD取り出しを検知した場合は再生と取得を中止し、表示を解除して未読み込みへ戻す。

2秒戻し・シーク

移動先は max(0, 現在位置ms − 2000)。移動前の再生／一時停止状態を保持する。シーク中の連続押下は直近の要求位置からさらに2000ms減算し、最新の要求を優先する。完了後はエンジンが報告する実際の位置を採用し、字幕を再判定する。失敗時は架空の位置を表示せず、実際の位置を再取得して通知する。

停止は現在タイトルの0msへ戻して再生待機にする。タイトル切替は取得処理・シーク要求を取り消し、一覧を解除して新タイトルを読み込む。チャプター移動は移動前の再生状態を維持する。

5. 字幕取得・表示・同期

  1. 選択タイトルのトラックを列挙し、言語コードから英語・日本語へ対応付ける。言語不明の場合は番号を表示して利用者が割り当てられるようにする。
  2. 有効なキャッシュがあれば読み込む。なければワーカーで両言語の字幕取得を開始し、取得済みのまとまりから表示する。
  3. 開始・終了時刻をタイトル先頭基準のミリ秒へ正規化する。再生側との時刻原点の差は取得側で補正し、GUIで個別補正しない。
  4. 画像とメタデータを検証して登録し、選択言語の時刻順一覧を更新する。
  5. 再生中は暫定100ms間隔で実再生時刻を取得し、start_ms ≤ t < end_msの全字幕を強調する。シーク・言語切替時は即時再判定する。

字幕の空白区間は強調を解除。手動スクロール中は現在字幕の判定は続け、自動スクロールだけを停止する。言語切替と「現在の字幕へ」で追従を有効にする。重複する字幕はすべて強調し、先頭の該当行を表示する。

「取得中」「字幕なし」「取得失敗」を区別する。取得途中の範囲へシークした場合は「この位置の字幕を取得中」と表示し、前の字幕を現在行として残さない。字幕なしはトラック列挙または取得完了で判定し、途中の0件を字幕なしと断定しない。

字幕の直接取得バックエンドは詳細設計・実装で選定する。ここでは画像と時間を返す契約を定める。性能や取得に問題がある場合は、事前処理した同じ形式のデータを読み込む代替方式へ切り替える。リアルタイムOCRは導入しない。

データ主要項目制約・用途
MediaInfo / TitleInfomedia_id、ドライブ、title_id、duration_ms、チャプター、トラック再生中の媒体を識別。タイトル番号と話数は同一視しない。
SubtitleTracktrack_id、language、title_id、取得状態languageはen / ja / und。媒体内の元トラック番号を保持。
SubtitleCuecue_id、track_id、start_ms、end_ms、image_path0 ≤ start_ms < end_ms。画像参照はキャッシュ内の相対パス。重なる時刻を許容。

キャッシュ

保存先はWindowsのユーザー別アプリデータ領域配下 dvd_player/cache/。配下を媒体ID／タイトルID／トラックIDで分け、JSONとPNG画像を置く。媒体IDはラベルだけに依存せず、媒体構成等から作る識別情報を併用する。識別方式の具体的な計算は詳細設計で定める。

一時ファイルに書いてから置換し、中断した保存を完成済みとして扱わない。JSONの型、時刻、パスを検証し、親ディレクトリへの参照やキャッシュ外への絶対パスは拒否する。画像は表示範囲付近だけ読み込み、メモリ上の画像数に上限を設ける。上限値とキャッシュ削除方針は実測で調整する。

初版では再生位置・学習履歴・利用者設定を永続化しない。キャッシュは再生成可能な補助データとし、保存できなくても可能な範囲でメモリ上の字幕表示を継続する。

7. 主要処理フローと内部インターフェース

起動・読み込み

依存環境確認 → 画面生成 → ドライブ列挙 → 読み込み要求 → 旧処理の中止と世代更新 → タイトル列挙 → タイトル選択 → 再生エンジン準備 → 0msで待機 → 字幕取得開始。字幕取得完了を動画再生開始の必須条件にはしない。

言語切り替え

言語の選択を更新 → 該当トラックの一覧へ差し替え → 実際の再生時刻を取得 → 強調と追従を更新。再生・一時停止・シークの指示は出さない。

終了

新規操作停止 → ワーカーに中止通知 → タイマー停止 → 再生停止 → ワーカー終了確認 → VLC・媒体ハンドル解放 → 画面終了。終了中に届いたイベントを世代IDで無視する。待機中は状態表示し、無制限にGUIをブロックしない。具体的な待機上限は詳細設計で設定する。

境界要求（概念名）結果・通知
Controller → PlaybackServiceopen、select_title、play、pause、stop、seek_ms、set_volume、select_chapter、closeprepared、snapshot_changed、seek_completed、ended、failed
Controller → SubtitleSourcelist_tracks、load(media_id, title_id, track_id, generation)、canceltracks_ready、batch_ready、progress、completed、failed
同期処理 → 表示モデルset_language、update_time、set_follow現在cue_id群、表示対象行、取得状況

名称は責務を示す設計上の名前であり、既存ライブラリのAPI名ではない。非同期通知には媒体・タイトル・世代IDを含め、別タイトルの結果を混入させない。

8. 異常時・セキュリティ

状況表示と回復
VLC等の依存関係不足不足する構成要素を案内。再生操作を無効にし、終了・環境再確認を可能にする。
ドライブなし・DVDなし接続・挿入の案内と再列挙／再読み込みを提供。
非対応・再生失敗再生を停止し、対象を再選択できる状態にする。リージョン等の原因は確認できる場合だけ表示。
字幕なし言語タブ内で案内。動画と他言語の表示は継続。
字幕取得失敗失敗した言語・処理を案内し、再取得を可能にする。動画は継続。必要なら事前処理方式を検討。
画像・キャッシュ破損対象データを無効化して再取得。壊れた画像は代替表示。
容量不足・保存不可永続キャッシュを停止して通知。可能ならメモリ表示を継続。
シーク・チャプター失敗実際の位置と状態へ表示を戻して通知。連打による要求を無制限に蓄積しない。

映像・字幕は外部送信しない。実行ログはユーザー別アプリデータ領域のlogs配下に保存し、エラーコード、処理種別、タイトル番号などに限定する。字幕本文・画像・秘密情報をログへ記録しない。GitSecurityToolによるコミット前検査を継続する。

単体確認は時刻検索・境界・状態遷移・世代IDによる古い結果の破棄を中心とする。結合確認はDVD実機、シーク、タイトル切替、字幕取得と同期を対象にする。同期誤差の暫定目標±300msは実再生時刻と字幕表示の比較で評価し、ポーリング間隔だけで達成したと判断しない。

詳細設計・実装で確定する事項

  1. 字幕画像・時刻を取り出すバックエンドと、DVDの再生時間軸への対応。
  2. 媒体識別方法、取得済み範囲の表現、画像メモリ上限・キャッシュ管理。
  3. 対応するWindows・VLC等のバージョン、ワーカー中止と終了待機の上限。
  4. 実媒体で問題が出た場合の事前処理方式と、同一タイトルであることの検証。

これらは詳細実装上の残課題であり、字幕が取得可能という合意済みの前提を変更するものではない。
