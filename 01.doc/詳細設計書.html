DVD字幕抽出の実装

dvdvideo対応FFmpeg full 9.0.2とffprobeを利用する。英語・日本語の全トラックを1回の入力で読み出し、画像を透過PNGとミリ秒時刻へ変換する。約5秒ごとの途中解析では書込中の可能性がある最新2画像を除外し、終了が確定した字幕とcoverageを保存する。中止後も取得済み範囲を利用できる。未知言語は手動で割り当てる。

5. 画面ウィジェット・イベント

初期1450×800、最小1100×600。左右の分割領域の初期指定は760：640で、利用者が幅を調整できる。左に映像、右に英語・日本語を時刻順にまとめた1つの字幕一覧を配置する。各行に言語・開始時刻・画像または文字を表示し、両言語の現在行を強調する。画像は最大約64px高、文字は最低20pt。上部の「字幕」メニューで各言語のトラックを選び、一覧で選択した言語をSRT読込・OCR操作の対象とする。言語の選択やトラック変更で再生位置・再生状態を変えない。

濃紺とミントの配色、映像・字幕カード、下部の再生操作・字幕操作・音量をまとめたバーを使用する。操作アイコンは30×30pxで、説明をツールチップとアクセシブル名に設定する。手動スクロールで追従を停止し、「現在の字幕へ」で再開する。

MainWindowがWindowsの映像出力ハンドルをPlayerへ渡す。シークスライダーは0～10000をタイトル長へ換算し、ドラッグ確定時に要求する。音量は0～100、初期70。字幕の選択行と言語ごとの現在行を分けて管理する。theme.pyのSubtitleDelegateが言語・時刻・画像／文字・強調を描画する。

6. 再生制御・2秒戻しの詳細

読み込みと停止

ドライブを読み込み、タイトルを選択すると旧世代を無効化し、再生・字幕の状態を解除する。新タイトルの準備完了と0msへの位置設定を確認してREADYとする。停止ボタンと自然終端は、先頭へ戻してREADYにする。初期化のため内部的にエンジンが再生状態を経由する場合も、準備完了前にPLAYINGとして通知しない。

2秒戻し

on_rewind():
  if closing or not seekable or actual_position is None: return
  base = latest_requested_target if seek_pending else actual_position
  target = max(0, base - 2000)
  request_seek(target, preserve_original_state=True)

連続押下で10秒→8秒→6秒と要求位置を累積する。実エンジンへの位置要求は同時に1件とし、処理中に追加要求があれば最新の目標を1件だけ保持する。完了時に保留目標があれば次を送り、古い完了通知で表示を巻き戻さない。スライダーの絶対位置要求は保留目標を置き換える。

位置要求の完了判定

アダプターは位置変更イベント／実時刻を確認して完了を通知する。暫定で要求位置との差500ms以内、または到達確認後に再生が進んだと判定できる場合を成功とし、境界・キー位置依存の挙動を実機で調整する。監視タイムアウトは暫定5秒。目標値を実測位置として表示しない。タイムアウト時はエンジンの現在位置を再取得し、保留要求を解除して警告する。

位置変更の開始前にPLAYING / PAUSED / READYを保存し、最後の要求完了時に復元する。処理中の再生／一時停止操作は復元先状態を更新する。停止・タイトル変更・終了は位置要求を取り消す。チャプター移動も同じ排他制御と状態保持を使う。

READYでシークした場合は移動先で待機状態を維持し、停止操作は0msへ戻す。映像の位置精度は媒体とエンジンに依存するため、2秒戻しの計算値と実際の到達位置は別に記録・検証する。

7. 字幕処理アルゴリズム

トラックの選択・取得

  1. 字幕トラックを列挙し、言語コードをen / ja / undへ正規化する。
  2. enとjaそれぞれ最初のトラックを初期選択。undは番号付きで表示し、利用者が英語・日本語へ割り当てられるようにする。
  3. キャッシュが一致すればロードする。未完了キャッシュは表示可能な範囲だけ使い、取得を再実行してcue_idで統合する。
  4. 両言語の全トラックを単一FFmpeg入力からまとめて取得する。再生との競合が大きい場合は利用者が取得を中止できる。
  5. 取得画像を必要部分へ切り出し、透明度・パレットを反映したPNGとして扱う。タイトル先頭を0msとする時刻へ変換する。

原時刻の単位・原点・DVD内の連結区間はバックエンドで正規化し、同じエピソードの再生時刻と対応付ける。終了時刻不明の字幕は勝手な長さを付けず、バックエンドの表示終了情報で確定する。取得不能なデータは行単位でエラーとし、走査済み範囲から除外する。

同期と重複区間検索

トラックごとに(start_ms, end_ms, cue_id)でソートし、開始時刻の配列と終了時刻の累積最大値を保持する。時刻t以下で始まる最後の位置を二分探索し、後方へ走査する。終了時刻の累積最大値がt以下になれば、それ以前に有効な字幕はないため打ち切る。各行はstart_ms ≤ t < end_msで判定し、該当する全行を返す。通常の重複は保持し、同じcue_idの再受信だけを更新する。

sync(t, track):
  if t is None: clear_highlight(); return
  if not coverage_contains(t): show_loading_at_position(); clear_highlight(); return
  active = repository.active_at(track, t)
  highlight(active)
  if follow and active: scroll_to(first_active_row)

GUIのタイマーは暫定100ms。シーク・タイトル準備・言語切替・batch追加後は即時再評価する。現在cue_id群が変わらない場合は強調表示を更新しない。手動スクロールは追従だけ解除し、同期は継続する。空白区間は強調なし、取得済み範囲外は取得中、完了後の0件は字幕なしを表示する。

代替取得

直接取得に問題がある場合は事前処理方式のSubtitleSourceへ差し替える。読み込むデータは同じ正規化済み字幕・coverage契約に適合させる。媒体・タイトル・トラックの一致を検証し、単なるファイル名の一致では採用しない。実際の事前処理ツールは問題発生時に選ぶ。

8. キャッシュ形式・ファイル処理

字幕の既定保存先はプロジェクトルートのsubtittle/<DVD名>/<DVD識別子のSHA-256>/title-XX/。title-XXは1始まり、内部title_idは0始まり。DVD名はファイル名として安全な文字へ変換し、媒体IDはIFO情報から計算する。トラック別の<track_id>/manifest.jsonとimages/、タイトル別のlanguage_map.json、subtitles.en.srt・subtitles.ja.srt、ocr/を保持する。

DVD_PLAYER_DATA_DIR指定時は、その配下のsubtittle/とlogs/を使う。未指定時のログは%LOCALAPPDATA%/dvd_player/logs/。ログは2MiB・バックアップ3世代。字幕保存の上限は既定512MiBで、容量管理と破損データの無効化を行う。字幕・OCR出力はGit管理外とする。

manifestのschema_versionは1。media_id、title_id、language（en/ja）、track_id、complete、coverage、cuesを持つ。各cueはcue_id、start_ms、end_msとimage_pathまたはtextを持つ。0 ≤ start_ms < end_ms、cue_id重複禁止、画像の外部パス参照禁止。画像字幕と文字字幕を別トラックとして保持し、SRTの再読込で同じ言語の文字トラックを更新する。JSONは一時書込後に置換し、取得済み範囲が短くなる途中結果は採用しない。保存に失敗しても可能な範囲で現在の字幕表示を継続する。

媒体識別はplayback.pyのmedia_identity、字幕ルートはstorage.pyのsubtitle_data_dir、タイトル別のパスはCacheStore.title_dirが担当する。manifestはcore.pyのread_manifestで検証する。CacheStoreはRLockで更新を直列化し、保存先の容量を管理する。上限を超える保存や破損データをそのまま採用しない。

9. 非同期・取消・終了

GUI更新はGUIスレッドのみ。DVD走査と字幕取得はワーカーで実行する。ワーカーは中止トークンを処理単位ごとに確認し、画像デコード・ファイル書込の境界でも確認する。ブロックする外部処理はタイムアウトや中断可能な方式でアダプターを実装する。

on_title_change(new_title):
  generation += 1
  cancel_old_workers_and_position_requests()
  clear_subtitles_and_playback_view()
  prepare_title(new_title, generation)

on_result(result):
  if closing or result.context != current_context_for_result: return
  apply_validated_result(result)

トラックごとのcontextを照合し、再取得時も要求IDを更新して旧要求を無効にする。キャンセルは即時完了を仮定せず、遅れて返った結果を反映しない。媒体へのアクセスはワーカー終了前に解放しない。

終了シーケンス

  1. CLOSINGへ移行し操作を無効化。世代を更新して後続通知を拒否。
  2. タイマー停止、位置要求取消、字幕取得へ中止要求、再生停止。
  3. GUIを動かしたままワーカー終了を待つ。暫定5秒を超えたら「終了処理中」を表示し、アダプターの安全な中断を要求する。
  4. ワーカー完了後に媒体・VLCを解放し、終了する。

Pythonスレッドを強制終了して共有資源を解放しない。中断不能なバックエンドを選ぶ場合は別プロセス化し、終了手順を追加する。アプリが応答しない待機にならないことを実機で確認する。

Subtitle Edit連携の詳細設計追記

Cueにtext（任意の文字列）とimage（任意の画像参照）を持たせ、文字字幕はQListWidgetへプレーンテキストとして描画する。20pt以上、改行・折返しを反映した行高とし、画像展開を行わない。時刻検索・現在行強調は共通のCueIndexを使用する。

subtitle_edit.pyがSRT解析、BDN XML／SRT書き出し、実行ファイル検出と起動を担当。SRTは20MiB・100,000件・1件10,000文字を上限とし、時刻逆転・空本文を拒否。UTF-8 BOM、UTF-16 BOM、CP932を読み込み、装飾タグを表示用に除去する。キャッシュはmedia/title/languageのテキストトラックへ原子的に保存し、修正後の読み込みで置換する。

画像は25fps・Version 0.93のBDN XMLとPNGへ書き出す。時刻の丸めは通常±20ms以内。テキストはUTF-8 SRTへ書き出し、ミリ秒を保持。毎回新規フォルダを使用。外部プロセスへは実行ファイルと字幕パスを分離した引数リストで渡し、shellは使用しない。

書き出し・読み込みは専用ワーカーで行い、現在の媒体・タイトルの世代と一致した結果だけを表示する。キャッシュ更新はRLockで直列化。SRTの元ファイル位置と外部実行ファイルの選択はセッション内で保持し、環境変数SUBTITLE_EDIT_PATHにも対応。OCRと保存後の取り込みは手動で、ファイル監視や自動OCRは行わない。

過去の連携追加時に確認済みなのは54自動テスト、テキストGUIプレビュー、公式5.4.0のSHA256照合と実DVD字幕3件の書き出し・プロセス起動。外部OCR画面はアプリ承認タイムアウトで未確認。連携手順を参照。
